# Security

Security fixes target the current `main` branch. Sun-Ray Lab is a client-side application; it has no hosted account system or application server.

For a suspected vulnerability, use GitHub's private vulnerability reporting option if it is available on this repository. Otherwise, use a private contact method listed on [the maintainer's profile](https://github.com/mahdi-salmanzade) before sharing sensitive details publicly. Include the affected revision, a minimal reproduction, and the impact you observed. Do not include credentials or private assets.

Rendering defects and ordinary bugs can be reported in [GitHub Issues](https://github.com/mahdi-salmanzade/sun-ray-lab/issues).
